# Cline VS Code 项目功能与源码包对照

> 目标：从“用户能做什么”反查“功能由哪些源码包实现”  
> 范围：VS Code 扩展、React Webview、Agent Core、Standalone 与测试辅助功能

## 1. 功能全景

项目的功能可分成 22 个领域：

1. VS Code 扩展激活与入口；
2. AI 对话与自主任务循环；
3. Plan/Act、YOLO、Auto Approve；
4. 文件读取、搜索、创建和修改；
5. 终端命令执行；
6. 浏览器自动化与网页获取；
7. 上下文收集、Mentions、规则和 Workflows；
8. Prompt 与模型能力适配；
9. 多模型供应商配置；
10. MCP 扩展；
11. Hooks；
12. Skills；
13. Subagents；
14. Checkpoints、Diff 和恢复；
15. 任务历史、导出和收藏；
16. 账号、认证、组织与额度；
17. 设置、远程配置和持久化；
18. Worktrees 与多根工作区；
19. VS Code 编辑器增强功能；
20. 通知、Banner、遥测和错误诊断；
21. Standalone/外部宿主；
22. 构建、测试、发布和公开 API。

## 3. VS Code 扩展入口功能

### 3.1 激活与初始化

功能：

- 响应 `onLanguage`、`onUri`、`onStartupFinished` 等激活事件；
- 初始化 VS Code Host Provider；
- 迁移旧版 VS Code State；
- 导出数据到 `~/.cline/data` 共享存储；
- 初始化 StateManager、错误、遥测、后台同步；
- 注册 Webview、Commands、URI Handler 和 Diff 文档 Provider；
- 监听 Secret 跨窗口变化；
- 停用时释放 Task、MCP、Hooks、遥测和 Watcher。

源码：

- `src/extension.ts`
- `src/common.ts`
- `src/registry.ts`
- `src/hosts/vscode/vscode-to-file-migration.ts`
- `src/core/storage/state-migrations.ts`

配置：`package.json` 的 `activationEvents`、`contributes` 和 `main`。

### 3.2 Activity Bar 与 Webview

功能：在 Activity Bar 显示 Cline 图标和 Sidebar，加载生产 Bundle 或开发 Vite HMR 页面，配置 CSP、nonce 和资源白名单。

源码：

- `src/core/webview/WebviewProvider.ts`
- `src/hosts/vscode/VscodeWebviewProvider.ts`
- `webview-ui/src/App.tsx`
- `webview-ui/src/Providers.tsx`

## 4. AI 对话与自主任务

### 4.1 新建、恢复、取消和清空任务

用户可以：

- 输入文本、图片和文件创建任务；
- 从历史记录恢复任务；
- 中止流式回复；
- 取消后台命令；
- 清空当前任务并开启新任务；
- 对 Ask 类型消息做批准、拒绝或文本回复。

源码：

- `src/core/controller/index.ts`
- `src/core/controller/task/newTask.ts`
- `showTaskWithId.ts`、`cancelTask.ts`、`clearTask.ts`、`askResponse.ts`
- `src/core/task/index.ts`
- `src/core/task/TaskState.ts`
- `webview-ui/src/components/chat`

### 4.2 流式回答

功能：

- 流式显示普通文本、Reasoning、Tool Call 和用量；
- 合并高频增量，优化远程工作区延迟；
- 中途执行工具或等待用户审批；
- 请求失败自动指数退避重试；
- 记录首 Token 时间、Token、Cache 和 Cost。

源码：

- `StreamChunkCoordinator.ts`
- `StreamResponseHandler.ts`
- `TaskPresentationScheduler.ts`
- `message-state.ts`
- `controller/ui/subscribeToPartialMessage.ts`
- Webview `ExtensionStateContext.tsx`、Chat Rows。

### 4.3 Agent 循环

功能：模型根据任务选择工具，工具结果作为下一轮输入持续执行，直到调用 `attempt_completion`、被取消或失败。

源码：`Task.startTask()`、`initiateTaskLoop()`、`recursivelyMakeClineRequests()`、`presentAssistantMessage()`。

### 4.4 用户反馈

功能：

- 对工具操作批准或拒绝；
- 在执行过程中追加文字、图片和文件；
- 对完成结果提供反馈；
- 对模型连续错误提供纠正建议；
- 点赞/点踩任务结果并记录反馈。

源码：

- `Task.ask()` / `handleWebviewAskResponse()`
- `core/controller/task/taskFeedback.ts`
- `components/chat/OptionsButtons.tsx`
- `TaskFeedbackButtons.tsx`
- `chat-view/hooks/useMessageHandlers.ts`

## 5. Plan、Act、YOLO 与审批控制

### 5.1 Plan/Act 双模式

功能：

- Plan 模式进行分析和规划；
- Act 模式执行修改；
- 可为两种模式选择不同 Provider、Model、Reasoning Effort；
- 严格 Plan 模式禁止文件写入类工具；
- Plan 回复后可一键切到 Act。

源码：

- `Controller.togglePlanActMode()`
- `controller/state/togglePlanActModeProto.ts`
- `PlanModeRespondHandler.ts`
- `ActModeRespondHandler.ts`
- `prompts/system-prompt/components/act_vs_plan_mode.ts`
- Webview Settings 和 Chat Mode Switch。

### 5.2 Auto Approve

功能：按工具类别自动批准读取、编辑、命令、浏览器、MCP 等操作，并可控制通知。

源码：

- `src/core/task/tools/autoApprove.ts`
- `src/shared/AutoApprovalSettings.ts`
- `webview-ui/src/components/chat/auto-approve-menu`
- `controller/state/updateAutoApprovalSettings.ts`

### 5.3 YOLO Mode

功能：尽量不等待人工确认地持续执行，同时仍受企业 Remote Config、工具权限、错误上限和安全边界约束。

源码：Task、ToolExecutor、State Settings、Feature Settings UI。

### 5.4 Focus Chain / Todo

功能：

- 生成和维护任务检查清单；
- 显示完成/未完成数量；
- 文件变更后同步；
- 从 UI 打开 Focus Chain 文件。

源码：

- `src/core/task/focus-chain`
- `src/shared/FocusChainSettings.ts`
- `components/chat/task-header/FocusChain.tsx`
- `controller/file/openFocusChainFile.ts`

## 32. 功能实现的核心主线

绝大多数功能最终会落到下面五条主线之一：

```text
UI 功能       -> Webview Component -> Proto RPC -> Controller Handler
Agent 功能    -> Task -> Prompt/Context -> Model -> ToolExecutor
IDE 功能      -> HostProvider -> VS Code/External Adapter
扩展功能      -> MCP / Hooks / Skills / Subagents
状态功能      -> StateManager -> StorageContext -> State Streaming -> React Context
```

掌握这五条主线后，功能目录虽然庞大，但定位方式是稳定的。
