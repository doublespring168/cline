可运行的示例位于 [SDK 仓库](https://github.com/cline/cline/tree/main/apps/examples)，并按难度组织：

| 示例 | 难度 | 描述 |
|---------|------------|-------------|
| [quickstart](https://github.com/cline/cline/tree/main/apps/examples/quickstart) | 初级 | 发送一个提示词，并以流式方式输出响应（约 15 行） |
| [cli-agent](https://github.com/cline/cline/tree/main/apps/examples/cli-agent) | 初级 | 带有 shell 工具的交互式终端聊天 |
| [code-review-bot](https://github.com/cline/cline/tree/main/apps/examples/code-review-bot) | 中级 | 具有自定义工具和结构化输出的 AI 代码审查器 |
| [multi-agent](https://github.com/cline/cline/tree/main/apps/examples/multi-agent) | 高级 | 具有流式 Web UI 的并行智能体 |
| [desktop-app](https://github.com/cline/cline/tree/main/apps/examples/desktop-app) | 高级 | 完整的 Tauri + Next.js 桌面应用程序 |
