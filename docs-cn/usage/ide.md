## 前提条件

开始之前，请确保你已：

- 在编辑器中安装 Cline（[安装指南](/getting-started/installing-cline)）
- 连接 AI 模型（[模型设置](/getting-started/authorizing-with-cline)）

如果尚未完成这些操作，请先完成，然后再回到这里。

## 第 1 步：打开项目文件夹

Cline 需要一个工作区，即计算机上供它创建和编辑文件的文件夹。你将打开一个空文件夹，让 Cline 可以在一个干净的位置构建待办事项应用。

<Tabs>
  <Tab title="VS Code / Cursor / Windsurf">
    1. 前往顶部菜单栏中的 **文件 → 打开文件夹**
    2. 在计算机上新建一个文件夹（例如，在桌面上将其命名为 `todo-app`）
    3. 选择该文件夹并点击 **打开**

    现在，编辑器左侧边栏顶部应显示该文件夹名称。由于这是新文件夹，文件资源管理器（左侧面板）将为空。
  </Tab>
  <Tab title="JetBrains">
    1. 前往顶部菜单栏中的 **文件 → 打开**
    2. 在计算机上新建一个文件夹（例如，在桌面上将其命名为 `todo-app`）
    3. 选择该文件夹并点击 **确定**

    现在，编辑器左侧的项目面板中应显示该文件夹名称。由于这是新文件夹，其中将为空。
  </Tab>
</Tabs>

<Warning>
如果跳过此步骤且未打开文件夹，Cline 将不知道应在哪里创建文件。开始任务前，请务必先打开一个文件夹。
</Warning>

## 第 2 步：打开 Cline 面板

Cline 面板是你与 Cline 沟通的聊天界面。你需要先打开它，才能向 Cline 发出任何指令。

<Tabs>
  <Tab title="VS Code / Cursor / Windsurf">
    查看编辑器最左侧（或最右侧）的**活动栏**，也就是竖直排列的一列图标。找到 **Cline 图标**（看起来像一个小机器人）并点击它。

    此时会打开一个显示 Cline 聊天界面的面板。你将看到：
    - 底部有一个用于输入消息的**文本输入框**
    - 上方有一个显示 Cline 回复的**聊天区域**
    - 面板右上角有一个**设置齿轮图标**

    <Tip>
    **找不到 Cline 图标？** 使用 `Cmd+Shift+P`（Mac）或 `Ctrl+Shift+P`（Windows/Linux）打开命令面板，输入 **"Cline：在新标签页中打开"**，然后按 Enter。这会在完整的编辑器标签页中打开 Cline，也能提供更大的屏幕空间。
    </Tip>
  </Tab>
  <Tab title="JetBrains">
    前往顶部菜单栏中的**视图 → 工具窗口 → Cline**。Cline 面板将在编辑器右侧打开。

    你将看到：
    - 底部有一个用于输入消息的**文本输入框**
    - 上方有一个显示 Cline 回复的**聊天区域**
    - 面板右上角有一个**设置齿轮图标**
  </Tab>
</Tabs>

## 第 3 步：向 Cline 分配任务

现在，你将告诉 Cline 要构建什么。你可以像使用聊天应用一样，在文本输入框中输入消息与 Cline 沟通。

1. **点击 Cline 面板底部的文本输入框**
2. 将以下提示词**粘贴（或输入）**到文本输入框中：

```text
Build a todo app in a single HTML file. Include:
- Input field to add new tasks
- List that displays all tasks
- Checkbox to mark tasks complete (with strikethrough styling)
- Button to delete individual tasks
- Clean, modern design with CSS
- All JavaScript inline in the same file
```

3. 按键盘上的 **Enter**（或点击**发送**按钮）发送消息

Cline 现在会读取你的消息并开始生成回复。当 Cline 思考你的请求时，你会看到文本出现在聊天区域中。

## 第 4 步：了解 Plan 模式与 Act 模式

Cline 收到任务后，可能会以两种模式之一开始工作。查看 **Cline 面板底部**，你会看到一个显示 **"Plan"** 或 **"Act"** 的切换按钮。

### 如果 Cline 处于 Plan 模式

在 Plan 模式下，Cline **只进行交流**。它会分析你的请求并讨论实现方法，但**不会**创建或修改任何文件。你会看到 Cline 描述它计划构建的内容，但项目文件夹中暂时不会发生任何变化。

这对于需要先讨论实现方法的复杂任务很有用。你可以：
- 就 Cline 的计划向它提问
- 建议调整实现方法
- 澄清你的需求

**当你准备好让 Cline 开始编写代码时**，点击面板底部的切换按钮，从 **"Plan"** 切换到 **"Act"**。随后 Cline 将开始提出实际的文件变更。

### 如果 Cline 处于 Act 模式

在 Act 模式下，Cline 会立即开始创建文件和编写代码（但在进行任何变更前仍会请求你的批准，详见下一步）。

<Note>
在本教程中，你需要使用 **Act 模式**，以便 Cline 创建待办事项应用。如果底部显示 "Plan"，请点击它切换到 "Act"。有关何时使用各模式的更多信息，请参阅 [Plan 和 Act 指南](/core-workflows/plan-and-act)。
</Note>

## 第 5 步：批准变更

未经你的许可，Cline **绝不会**修改你的文件。在创建或编辑任何文件之前，Cline 会准确展示它想要执行的操作，并等待你的批准。

你会在聊天中看到以下内容：

1. **Cline 提出文件变更。** 聊天中会出现一个区域，其中显示文件路径（例如 `index.html`）以及 Cline 想要写入的代码。新增代码行会以**绿色**高亮显示。

2. **出现批准或拒绝按钮。** 在建议变更的正下方，你会看到两个按钮：
   - **批准**（对勾）：点击此按钮允许 Cline 创建或编辑文件。文件将写入你的项目文件夹。
   - **拒绝**（X）：点击此按钮停止 Cline，随后改为提供其他指令。

3. 点击**批准**，让 Cline 创建 `index.html` 文件。

批准后，Cline 会将该文件写入你的项目文件夹。你应当会在编辑器的文件资源管理器（左侧面板）中看到 `index.html`。

<Note>
每次创建文件、编辑文件和执行终端命令，都需要你的明确批准。你始终可以控制项目中发生的变更。熟悉 Cline 后，可以启用[自动批准](/features/auto-approve)，跳过特定操作的确认步骤。
</Note>

## 第 6 步：查看创建的应用

通过之前的提示词，Cline 已在你的项目文件夹中创建 `index.html` 文件。现在，让我们在 Web 浏览器中打开它来查看应用。

<Tabs>
  <Tab title="macOS">
    **选项 A：使用终端**

    如果 Cline 运行了终端命令来打开文件，该文件可能已经打开。否则，你可以在编辑器中打开终端（`` Ctrl+` `` 或从菜单中选择**终端 → 新建终端**）并输入：
    ```bash
    open index.html
    ```

    **选项 B：使用访达**

    在编辑器的文件资源管理器（左侧面板）中右键点击 `index.html`，然后选择**"在访达中显示"**。随后在访达中双击该文件，使用默认浏览器打开它。
  </Tab>
  <Tab title="Windows">
    **选项 A：使用终端**

    在编辑器中打开终端（`` Ctrl+` `` 或从菜单中选择**终端 → 新建终端**）并输入：
    ```bash
    start index.html
    ```

    **选项 B：使用文件资源管理器**

    在编辑器的文件资源管理器（左侧面板）中右键点击 `index.html`，然后选择**"在文件资源管理器中显示"**。随后双击该文件，使用默认浏览器打开它。
  </Tab>
  <Tab title="Linux">
    **选项 A：使用终端**

    在编辑器中打开终端（`` Ctrl+` `` 或从菜单中选择**终端 → 新建终端**）并输入：
    ```bash
    xdg-open index.html
    ```

    **选项 B：使用文件管理器**

    在编辑器的文件资源管理器（左侧面板）中右键点击 `index.html`，然后选择**"打开所在文件夹"**。随后双击该文件，使用默认浏览器打开它。
  </Tab>
</Tabs>

**选项 C：Live Server（任意操作系统）**

如果你已在 VS Code 中安装 Live Server 扩展，请在文件资源管理器中右键点击 `index.html`，然后选择**"使用 Live Server 打开"**。这会在浏览器中打开应用，并在文件发生变化时自动刷新。

试用你新建的待办事项应用：添加几项任务、将它们标记为完成，然后删除它们。该应用完全在浏览器中运行，无需服务器或后端。

## 第 7 步：迭代项目

Cline 最强大的功能之一是它会记住你的整个对话。你可以请求变更，Cline 会修改现有代码，而不是从头开始。

**在同一个 Cline 聊天中**（不要开始新对话），点击底部的文本输入框并输入后续请求。下面是一些可以尝试的想法：

**添加持久化：**
```text
Add local storage so tasks persist when I refresh the page
```

**更改设计：**
```text
Switch to a dark theme with purple accent colors
```

**添加功能：**
```text
Add a filter to show all, active, or completed tasks
```

发送后续消息时，Cline 将：
1. 读取你当前的 `index.html` 文件，了解现有代码
2. 提出具体变更（以差异形式显示，新增行以绿色表示，删除行以红色表示）
3. 修改文件前等待你的批准

点击**批准**应用变更，然后刷新浏览器查看更新后的应用。

## 第 8 步：使用检查点撤销错误

Cline 会在每次完成变更后自动保存一个**检查点**。如果出现问题或你不喜欢某项修改，可以返回之前的任意状态。

### 如何找到检查点

在 Cline 面板中滚动浏览对话。在 Cline 执行变更的每个步骤旁，你会看到两个小按钮：

- **比较**：点击可准确查看该步骤中哪些文件发生了变化（变更前/后的差异）
- **还原**：点击可将项目回滚到该时间点的状态

### 如何还原

点击**还原**时，你会看到三个选项：

| 选项 | 作用 | 使用时机 |
|--------|--------------|----------------|
| **还原任务和工作区** | 将文件和对话都重置到该时间点 | 你想彻底返回并从该步骤重新开始 |
| **仅还原任务** | 保留当前文件，但还原对话上下文 | 很少需要使用 |
| **仅还原工作区** | 将文件重置到该时间点，但保留完整对话 | 你想尝试其他方法，但保留对话历史记录 |

**给初学者的建议：**如果你想撤销变更，但继续与 Cline 讨论不同的处理方式，请使用**"仅还原工作区"**。

<Tip>
检查点与 Git 相互独立。它们不会影响你的提交、分支或已设置的任何版本控制。
</Tip>

在[检查点指南](/core-workflows/checkpoints)中了解更多信息。

## 你学到了什么

你刚刚完成了 Cline 的核心工作流：

1. **打开项目文件夹**，为 Cline 提供工作区
2. **打开 Cline 面板**，并在聊天输入框中输入任务
3. **了解 Plan 与 Act 模式**以及如何在两者之间切换
4. 在 Cline 向磁盘写入任何内容前**批准文件变更**
5. 通过在同一对话中发送后续消息进行**迭代**
6. 使用**检查点**撤销错误并尝试不同的实现方法

从简单脚本到完整应用，这些模式适用于任何项目。你为 Cline 提供的目标上下文越丰富，得到的结果就越好。
