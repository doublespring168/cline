**网站：** [https://bailian.console.aliyun.com/](https://bailian.console.aliyun.com/)

### 获取 API 凭据

1.  **注册/登录：** 前往 [Alibaba Cloud Bailian Console](https://bailian.console.aliyun.com/)。创建账户或登录。
2.  **前往 API Keys：** 访问 API 密钥管理部分。
3.  **创建密钥：** 为你的应用程序生成新的 API 密钥。
4.  **复制密钥：** 立即复制 API 密钥并安全存储。

### 在 Cline 中配置

> 请参阅[授权与模型选择](/getting-started/authorizing-with-cline#%E8%8F%9C%E5%8D%95)。

1.  **打开 Cline 设置：** 点击 Cline 面板中的设置图标（⚙️）。
2.  **选择提供商：** 从 "API Provider" 下拉菜单中选择 "Alibaba Qwen"。
3.  **选择区域：** 根据你所在的位置选择 "International" 或 "China"。
4.  **输入 API 密钥：** 将你的 Qwen API 密钥粘贴到 "Qwen API Key" 字段中。
5.  **选择提供商模型：** 从 "Model" 下拉菜单中选择所需的模型。

### 提示和注意事项

-   **视觉支持：** VL（视觉-语言）模型支持用于多模态任务的图像输入。
-   **定价：** 请查看 [Alibaba Cloud Bailian Console](https://bailian.console.aliyun.com/)了解当前定价。
