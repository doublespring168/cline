MiniMax 提供具有大上下文窗口和有竞争力定价的 AI 模型，包括 MiniMax-M2 系列。

**网站：** [https://www.minimax.io/](https://www.minimax.io/)

### 获取 API 凭据

1.  **注册/登录：** 前往 [MiniMax Platform](https://www.minimax.io/platform)。创建账户或登录。
2.  **前往 API Keys：** 访问 API 密钥部分。
3.  **创建密钥：** 生成新的 API 密钥。
4.  **复制密钥：** 立即复制 API 密钥并安全存储。

### 在 Cline 中配置

> 请参阅[授权与模型选择](/getting-started/authorizing-with-cline#%E8%8F%9C%E5%8D%95)。

1.  **打开 Cline 设置：** 点击 Cline 面板中的设置图标（⚙️）。
2.  **选择提供商：** 从 "API Provider" 下拉菜单中选择 "MiniMax"。
3.  **输入 API 密钥：** 粘贴你的 MiniMax API 密钥。
4.  **选择提供商模型：** 从 "Model" 下拉菜单中选择所需的模型。

### 提示和注意事项

-   **大上下文：** 所有模型都支持 192K token 上下文窗口。
-   **推理支持：** M2.7 和 M2.5 支持用于复杂任务的扩展思考/推理。
-   **定价：** 请查看 [MiniMax 定价页面](https://www.minimax.io/platform/document/pricing)了解当前费率。
