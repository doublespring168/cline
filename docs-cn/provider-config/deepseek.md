**网站：** [https://platform.deepseek.com/](https://platform.deepseek.com/)

### 获取 API 凭据

1.  **注册/登录：** 前往 [DeepSeek Platform](https://platform.deepseek.com/)。创建账户或登录。
2.  **前往 API Keys：** 在平台的 [API 密钥](https://platform.deepseek.com/api_keys)部分找到你的 API 密钥。
3.  **创建密钥：** 点击 "Create new API key"。为密钥指定一个描述性名称（例如 "Cline"）。
4.  **复制密钥：** **重要：** 请_立即_复制 API 密钥。之后你将无法再次查看。请安全存储。

### 在 Cline 中配置

> 请参阅[授权与模型选择](/getting-started/authorizing-with-cline#%E8%8F%9C%E5%8D%95)。

1.  **打开 Cline 设置：** 点击 Cline 面板中的 ⚙️ 图标。
2.  **选择提供商：** 从 "API Provider" 下拉菜单中选择 "DeepSeek"。
3.  **输入 API 密钥：** 将你的 DeepSeek API 密钥粘贴到 "DeepSeek API Key" 字段中。
4.  **选择提供商模型：** 从 "Model" 下拉菜单中选择所需的模型。
