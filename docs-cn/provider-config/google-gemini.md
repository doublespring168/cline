Google Gemini 是 Google 的多模态 AI 模型系列，提供目前规模最大的上下文窗口之一，并在编码、推理和文档分析任务中表现出色。

**网站：** [https://ai.google.dev/](https://ai.google.dev/)

### 获取 API 凭据

1.  **注册/登录：** 前往 [Google AI Studio](https://aistudio.google.com/)。使用你的 Google 账户登录。
2.  **获取 API 密钥：** 前往 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)。
3.  **创建密钥：** 点击 "Create API Key"，然后选择或创建一个 Google Cloud 项目。
4.  **复制密钥：** 立即复制 API 密钥并安全存储。

### 在 Cline 中配置

> 请参阅[授权与模型选择](/getting-started/authorizing-with-cline#%E8%8F%9C%E5%8D%95)。

1.  **打开 Cline 设置：** 点击 Cline 面板中的设置图标（⚙️）。
2.  **选择提供商：** 从 "API Provider" 下拉菜单中选择 "Google Gemini"。
3.  **输入 API 密钥：** 将你的 Google AI API 密钥粘贴到 "Gemini API Key" 字段中。
4.  **选择提供商模型：** 从 "Model" 下拉菜单中选择所需的模型。

### 提示和注意事项

-   **定价：** 有关最新信息，请参阅 [Google AI 定价页面](https://ai.google.dev/gemini-api/docs/models/gemini)。
