当 Cline 拥有恰当的上下文，而不仅仅是更多上下文时，它的效果最好。`@` 提及让你可以引入与任务相关的文件和文件夹——无需复制、无需粘贴，也无需切换上下文。

你可以通过两种方式添加上下文：
- 在聊天输入框中键入 `@`，然后选择文件或文件夹
- 点击左下角的 **+** 按钮浏览文件或图像

## 快速参考

| 你想要的内容 | 语法 | 示例 |
|---------------|--------|---------|
| 文件内容 | `@/path/to/file` | `@/src/index.ts` |
| 文件夹内容 | `@/path/to/folder/` | `@/src/components/` |

对于其他上下文——git 历史记录、网页、终端错误——只需描述即可。Cline 会自行运行 `git log`、获取 URL 或读取输出。

## 文件提及

使用 `@/path/to/file` 引用任意文件。Cline 会看到完整的文件内容，包括导入、相关函数和周围上下文。

```text
Can you refactor the error handling in @/src/api/users.ts?
```

## 文件夹提及

使用 `@/path/to/folder/` 引用整个目录（请注意末尾的斜杠）。Cline 会看到文件夹结构和所有文件内容。

```text
Explain how the components in @/src/components/auth/ work together.
```

<Note>
在多根工作区中，请在路径前加上工作区名称：`@workspace-name:/path/to/file`
</Note>

## 拖放

将文件直接拖入聊天输入框，即可将它们添加到对话中。

<Note>
在 VS Code 中，将文件拖入聊天输入框时请按住 **Shift**。
</Note>

拖动工作区文件会自动创建文件提及。你还可以将 Finder 或文件资源管理器中的文件直接拖入 Cline。

### 支持的文件类型

Cline 支持工作区中的文本文件，以及文件系统中的图像、PDF、CSV 和 Excel 文件。

<Note>
图像需要多模态模型。请检查模型选择器，查看哪些模型支持图像输入。
</Note>

## 上下文菜单命令

右键点击选中的代码，无需键入内容即可使用 Cline。这是针对特定代码获取帮助的最快方式，因为它会自动将选中的文本及其文件位置作为上下文。

### 代码编辑器命令

| 命令 | 使用时机 |
|---------|-------------|
| **添加到 Cline** | 询问有关代码的问题、获取建议，或以特定代码作为上下文开始对话 |
| **使用 Cline 修复** | 快速修复所选代码中的错误、缺陷或问题 |
| **使用 Cline 解释** | 理解不熟悉的代码、复杂逻辑或正在审查的代码 |
| **使用 Cline 改进** | 获取重构建议、性能改进或更简洁的实现方式 |

当光标位于错误或警告上时，**使用 Cline 修复**也会出现在灯泡菜单（快速修复）中，让你可以轻松地就地修复问题。

### 终端命令

在终端中右键点击“添加到 Cline”，以获取以下方面的帮助：
- 构建错误和失败的命令
- 测试失败和堆栈跟踪
- 配置问题
- 任何需要帮助解读的终端输出

### 源代码管理命令

在源代码管理面板中，使用“生成提交消息”，根据暂存的更改创建由 AI 驱动的提交消息。Cline 会分析差异，并按照约定式提交模式编写描述性提交消息。
