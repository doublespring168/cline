Cline 在聊天中提供斜杠命令，帮助你管理对话并规划复杂的实施方案。

<Tip>
**刚开始使用斜杠命令？** 观看我们的[快速视频演示](https://youtu.be/MxS5Jerpf-o)，了解这些命令的实际运行方式。
</Tip>

## 斜杠命令

在聊天输入框中键入 `/` 以查看可用的斜杠命令：

| 命令 | 功能 |
|---------|--------------|
| `/newtask` | 使用从当前对话中提炼的上下文开始全新任务 |
| `/smol` | 压缩对话历史记录，同时保留必要上下文 |
| `/newrule` | 创建规则文件，向 Cline 说明你的偏好 |
| `/deep-planning` | 调查代码库、进行周密规划，然后创建实施任务 |
| `/explain-changes` | 为任意 git 差异生成 AI 解释（仅限 VS Code） |
| `/reportbug` | 使用诊断信息报告错误 |

### /newtask

`/newtask` 的作用类似开发者交接。它会将重要内容（总体计划、已完成的工作、相关文件、后续步骤）整理到一个拥有干净上下文窗口的新任务中，将工具调用和实现细节的杂乱信息留在原任务里。

我在处理复杂实施工作时会使用 `/newtask`。如果一个包含 10 个步骤的流程已经完成了 3 步，而我的上下文也已经用满 75%，我会使用 `/newtask` 提取关键决策、文件更改和进度，同时去除所有杂乱信息。

### /smol

`/smol`（或其别名 `/compact`）会压缩对话历史记录，同时保留必要上下文。与会创建新任务的 `/newtask` 不同，`/smol` 会将当前对话浓缩为一份全面的摘要，释放上下文窗口空间，同时让你能够在同一个任务中继续工作。

当你正深入进行调试或头脑风暴，需要在不丢失已有见解的情况下继续同一任务时，请使用 `/smol`。有关更多详细信息，请参阅 [Smol 命令](#%2Fsmol)。

### /newrule

`/newrule` 会创建一个规则文件，向 Cline 说明你的偏好。Cline 将引导你为沟通风格、编码标准、项目上下文和可复用实践设置准则。规则会保存到你的 `.clinerules` 目录，并自动加载到未来的对话中。

当你发现自己在不同任务中反复给出相同指令时，请使用 `/newrule`。有关规则的更多信息，请参阅 [Cline 规则](/customization/cline-rules)。

### /deep-planning

将 Cline 转变为一位一丝不苟的架构师，在编写任何代码之前调查你的代码库、提出澄清问题并创建全面的实施计划。深度规划遵循四步流程：

1. **静默调查** - Cline 探索你的代码库结构和模式
2. **讨论** - 针对需求和方案提出有针对性的问题
3. **创建计划** - 生成包含详细规格的 `implementation_plan.md`
4. **创建任务** - 创建包含可跟踪实施步骤的新任务

对于涉及代码库多个部分的功能、架构更改或复杂集成，请使用 `/deep-planning`。

### /explain-changes

<Note>
此命令仅在 VS Code 中可用。
</Note>

`/explain-changes` 会为任意 git 差异生成由 AI 驱动的解释。你可以解释上一次提交、未提交的工作、暂存的更改、特定提交、分支、PR 或任意范围的更改。

在审查代码、熟悉新代码库或了解发生了哪些更改时，请使用 `/explain-changes`。有关完整的用例和示例列表，请参阅[解释更改命令](#%2Fexplain-changes)。

### /reportbug

`/reportbug` 会收集诊断信息并帮助你报告 Cline 的问题。它会收集配置、近期错误和系统详细信息等相关上下文，使错误报告对开发团队更有帮助。

当你遇到意外行为、崩溃或想要报告的错误时，请使用 `/reportbug`。

## 通过斜杠命令使用技能

除了内置命令，你还可以使用斜杠命令直接从聊天中触发已启用的技能。

- 键入 `/` 打开命令建议。
- 选择一个技能命令（例如 `/aws-deploy`）。
- Cline 会加载该技能，并将其 `SKILL.md` 指令应用于任务。

任何已启用的技能都可以通过这种方式触发，让你无需每次重写相同指令，即可快速获得针对特定技能的指导。

有关设置和管理的详细信息，请参阅[技能](/customization/skills#%E4%BD%BF%E7%94%A8%E6%96%9C%E6%9D%A0%E5%91%BD%E4%BB%A4%E8%A7%A6%E5%8F%91%E6%8A%80%E8%83%BD)。
