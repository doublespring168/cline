**Cline 提供商**是开始使用 Cline 最简单的方式。

你无需管理多个提供商各自的 API 密钥，只需登录一次，即可直接在 Cline 中选择可用模型。

## 为什么使用 Cline 提供商

- **最快设置**：无需手动复制/粘贴 API 密钥
- **一个账户**：使用 Google、GitHub 或电子邮件登录一次
- **统一计费**：支持的模型共用一个余额
- **免费选项**：在选择器中查找标有 **免费**的模型

## 设置

<Steps>
  <Step title="打开 Cline 设置">
    点击 Cline 面板中的设置图标。
  </Step>

  <Step title="选择提供商">
    将 **API 提供商**设置为 **Cline**。
  </Step>

  <Step title="登录">
    点击**登录**，并在浏览器中完成身份验证。
  </Step>

  <Step title="选择模型">
    从**模型**下拉列表中选择一个模型。
  </Step>

  <Step title="验证">
    发送一条测试消息。如果 Cline 做出响应，则设置完成。
  </Step>
</Steps>

## 额度和用量

- 从你的 [Cline 控制面板](https://app.cline.bot/dashboard)添加额度
- 在 Cline 设置 → **查看用量**中查看用量
- 在 Cline 设置 → **切换组织**中切换组织
